## 验证方法

1. **界面及人工验证**：实际发现页、演唱会搜索、BV / 完整链接导入、播放入口、倍率弹层及歌曲缓存；用户确认歌曲声音正常，并手动确认书架歌曲封面能进入播放页并播放。
2. **系统媒体按键**：使用 Android 媒体暂停、播放事件，读取同一资源、同一分 P 的前后状态。
3. **调试接口验证**：为避免手机模拟触摸不稳定，对跨作品切换调用现有 `BookPlayer.playBookWithFallback`；听书初始化调用 `playBook`，听书倍率调用 `cycleSpeed`。实际 B 站请求、手机原生播放器、缓存和持久化仍正常执行，没有替换为模拟音源。
4. **只读交叉核验**：通过 Dart VM `getObject` 读取应用倍率、原生播放器倍率、位置、模式、错误及离线标志；只提取测试应用的相关偏好和缓存元数据。未向交付记录写入 Cookie、临时音频 URL 或原始运行日志。

## 自动操作限制与处理

- 手机微信输入法会把快速 ADB 字符输入当作拼音，并出现字符顺序变化。切换英文、降低输入速度、核对完整文本后才提交；不把输入失败当成链接解析失败。
- 部分卡片和热搜词的 ADB 点击没有触发。用户手动点击《种子》封面确认可以进入并播放；另用真实 `BookGridItem`、已解码封面和三列网格做临时 Widget 检查，封面 / 标题的普通点击及 120ms 同点按压共 4 次均触发 `onTap`，没有误触长按。这不能证明手机自动注入链路稳定。
- 熄屏测试完成后 ADB / Flutter 调试连接曾失去响应。仅重新连接该设备的 ADB 后恢复；测试应用 PID 保持不变。该现象记为调试连接限制，未据此判断应用崩溃。
