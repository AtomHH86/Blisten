## 当前结论

同一项目已具备 Android、Web、iOS 的平台目录与适配入口；继续共享四频道、收藏、最近收听、界面和播放规则。三种平台分别构建，不共用一个安装文件。

本阶段状态是 **A0 工程预览**：Web 生产入口及独立音频探针已编译成功，确定性测试通过；真实 B站请求、浏览器播放操作、iOS CI 编译及真机体验仍需补充运行结果。**PWA 真实来源跨域尚未通过验收，iOS 在线播放当前明确关闭。** 未部署公网 PWA，未生成或上传 TestFlight 包，不宣称三端功能对等。

## 能力边界

| 项目 | 本阶段行为 | 尚不能据此确认的能力 |
| --- | --- | --- |
| Web 账户 | 匿名使用，不读取、持久化 B站账号 Cookie | 账户登录、大会员权限及跨设备同步 |
| Web 缓存 | 明确提示暂不支持离线音频缓存，避免触发原生文件路径 | 离线音频、离线启动；本阶段关闭 Service Worker |
| Web 音频探针 | 独立入口，使用自行合成的同源低音量 WAV | B站音频可播、正式播放器全链路、Safari、锁屏与长时间后台 |
| Web 来源访问 | 浏览器直接请求，不伪造原生 Cookie / Referer，不部署媒体转发 | 真实搜索、导入、封面和媒体的跨域可达性 |
| iOS 宿主 | 已配置系统浏览器、Keychain、音频会话和中断适配代码 | 未经编译与真机测试的代码不能视作系统行为已通过 |
| iOS 在线音频 | 未配置可信证书链时失败关闭，界面说明预览限制 | 不关闭证书检查换取播放；真实证书链与错误证书拒绝仍待验证 |
| 发布 | Android 独立补丁与 A0 预览分开交付 | 本阶段没有 PWA 公网部署、iOS 签名、TestFlight 或 Store 发布 |
