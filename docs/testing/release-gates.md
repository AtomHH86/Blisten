## 签名与四包

用户已授权首次签名、打包、安装包测试，并在发布检查通过后上传 GitHub。使用项目打包脚本，不把 debug证书的release构建当正式包。签名私钥、密码、key.properties不入Git、日志或bundle。

1. 已创建 B听专用 RSA-4096 / PKCS12 证书，别名 `blisten`；公开证书 SHA256 为 `da58f45d2a4309fb420b8508c97b6652f64a8417e4c2d876f5303d3e08bc2ee0`。密码单独保存。
2. 本机备份已核对字节一致，隔离恢复后实际签名验证 JAR，并通过 `jarsigner -verify -strict`；恢复证书摘要一致。两份备份仍在同一台 Mac，受控外部备份待完成；本机恢复验证不等于已具备整机损坏后的恢复能力。
3. 同步pubspec.yaml与app_meta版本，versionCode递增。用正式脚本分别生成ARM64/ARMv7/x86_64/universal，记录真实大小、ABI、包名、版本、签名、SHA-256和16KiB静态报告。
4. 首次安装与覆盖升级均用候选包验证。B听包名与原阿B听书不同，不覆盖原应用；debug也与正式版独立。
5. 升级测试以合成收藏/设置/进度/缓存为样本，验证旧凭据迁移、收藏目录/模式、取消收藏标记、缓存索引与登录状态。不要对真实用户数据执行pm clear或卸载。
6. 回滚优先采用旧代码修复后提高versionCode、保持签名的新包，并测试新数据的兼容读取；不要把adb强制降级当用户回滚方案。卸载会删除应用私有数据，源码Git恢复不恢复用户手机数据。

本轮新增字段均兼容缺省旧数据；Cookie迁移后旧程序未必能读取隔离存储，应允许重新登录，不把账号会话放入导出/备份作为回滚手段。正式 APK 的首次安装与 universal 同版本覆盖通过，收藏、进度、深色主题、缓存保留；跨版本升级及回滚数据演练仍待验。

## 依赖与对外入口

[历史依赖审计](../reviews/2026-10-24-dependencies/README.md)保留旧预编译库的来源、许可证和安全公告结论。本轮已采集 [releaseRuntimeClasspath 图](../reviews/2026-10-24-dependencies/release-runtime-classpath.txt)，并固定源码自建三 ABI 音频库：mpv 0.35.1 加既有补丁、FFmpeg 6.1.6、Mbed TLS 3.6.7 加 pthread 补丁、固定 helper/framework，禁用 libxml2 与 DASH/IMF demuxer。六个 `.so` 的 ELF LOAD 对齐均为 16KiB；最终 APK 组成与 ZIP 对齐已通过；x86_64/API35 设备运行已验证，其他设备范围见上表。

对应源码材料已生成：27,017,370 字节，SHA256 `bf2d36734cf334b0c3310708130be5dff4c879ec7dee700aaca16a55369a9e41`。随包源码、补丁、配置和通知已核对 74 个文件哈希，并验证离线源码准备；尚不代表跨机完整重编译验证。发布时须将该材料与 APK 同批提供，并提供同版本应用源码。原生库完整哈希、源码锁与具体证据见[本轮记录](2026-10-24-apk-release.md)。

本轮发现并修复了原生播放器默认未启用 HTTPS 证书校验的问题：在线打开前显式启用验证并使用 Android 系统信任，配置失败停止打开。TLS 单元 7 项和 API35 x86_64 原生四个行为用例通过；一次被通知弹窗阻塞的运行未算作通过。测试 CA 仅在测试进程显式配置，没有进入生产资产或系统信任库。随后已通过 77 项完整原生行为回归、7 项最终 TLS/协议定向检查和真实 B 站游客播放；正式签名 APK 随后已单独安装验收，结果见本轮记录。

本机发布门槛已通过：真实 Gradle 对旧构建指纹/额外库的拒绝已通过，保留 mpv 的公告处置依据已保存于[原生发布记录](../reviews/2026-10-24-native-release-disposition.md)。最终 APK 与原生库/notices 的映射、正式包安装和同版本数据保留均已通过；对应源码与公开核验材料列入 Release 附件。当前最终单元日志为 Flutter 302 通过/1 跳过、Python 94 通过，静态分析无问题；成品检查结果另见本轮 APK 记录，不能把上述单元数量当作设备覆盖。反馈与更新入口已配置为 `AtomHH86/Blisten`，相关单元测试通过；更新包选择已修复为优先 universal，无通用包时回退发布页。

日常本机回归、独立联网检查、备份隔离与原生寿命检查的命令见[电脑测试指南](android-desktop-guide.md)。线上B站资源和平台限制变化独立于确定性回归。
