# 电脑 Android 测试方案

用户已确认：安装配置模拟器，补齐自动化测试；本次交付测试与打包脚本，正式四架构安装包稍后生成。

## 目标与范围

- 在当前 Intel/macOS 13 电脑运行带硬件加速的 x86_64 Android 模拟器，工具链使用持久目录。
- 保留现有听书、歌曲和演唱会规则；新增验证代码，不顺手重构产品。
- 单元/组件测试覆盖规则和页面；模拟器集成测试使用真实播放器及 Android 存储验证播放、倍速、续播和缓存。外部 API 可使用明确的固定响应，避免把 B 站可用性当作回归测试前提。
- 真实 B 站联网验证与固定数据测试分开记录。模拟器结果不代表所有厂商后台策略、蓝牙或电话打断都已验证。
- 提供一条命令执行测试、保存日志；默认仅操作专用模拟器和独立 debug 包，不使用连接的手机。
- 提供四架构 release 打包脚本，要求显式配置发布签名，输出实际大小、SHA-256、版本、最低 Android 版本、证书摘要及 ABI 清单。本次不生成正式包或发布。

## 验收

1. 加速检查成功，系统启动完成，能安装运行 x86_64 调试包。
2. 静态分析和现有/新增单元组件测试通过。
3. 模拟器集成测试实际执行通过，并保存结果；至少一次复跑验证可重复性。
4. 脚本失败时返回非零；缺少正式签名时打包脚本在构建前明确拒绝。
5. 中文教程给出已验证命令、覆盖范围和仍需实机验证的项目。
