# 启动更新修复设计

用户现象：1.1 手动可以发现更新，启动没有提示。当前源码在一次成功检查后24小时内不再自动检查，且回前台只处理已有结果。

本次规则：每次冷启动首页就绪后检查一次，旧的24小时成功时间不阻止启动检查；主题/界面重建不重复请求。保留手动检查、并发合并、后台/其他页面延迟呈现、失败不打扰、超时和严格同仓库下载地址验证。此修复不增加后台定时轮询，不改播放和数据规则。

发布说明只包含“新增功能”和“问题修复”面向用户的要点；开发过程留在验收文档。解析结构化发布说明时只提取上述段落，其他段落不进入弹窗；无上述段落时显示简短通用说明，避免展示原始技术长文。

验收：保存最近成功检查时间后重新冷启动仍请求并提示新版本；无新版本不弹窗；失败可手动重试；已有并发、导航、深浅色与200%字号用例保持通过；本机Android更新集成与正式包升级复核。旧1.1必须手动升级一次才能使用新规则。

范围：只修Android更新行为与用户说明，补丁版本1.2.1+4。PWA/iOS在后续独立提交推进，共用Blisten仓库，不改旧正式标签。
