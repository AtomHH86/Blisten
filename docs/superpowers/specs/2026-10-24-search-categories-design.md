# 搜索四个并列分类

用户要求：把分布在各内容搜索内的 UP 主提升到与听书、歌曲、演唱会并列。此次授权覆盖这一导航调整，普通实现细节按项目规范执行。

- 搜索页始终显示四个同级 ChoiceChip：听书、听歌、听现场、UP 主。前三项沿用既有品牌文案，分别对应听书、歌曲、演唱会，不改发现页或播放类型枚举。
- 删除搜索后的“内容结果 / UP主”第二层切换。未输入时可先选分类；已搜索后切换保留输入并重新查询。立即显示新分类与加载状态；失败保留分类和关键词，可原地重试。快速切换/清空后旧响应不覆盖。
- UP 主查询独立调用用户搜索 API，不按听书/歌曲/现场过滤。共享现有搜索历史；UP 空搜索不展示某一内容模式的热门词。UP 列表可分页，按 mid 去重，失败保留结果并重试原页。
- 搜索页保留最近内容模式作为链接导入和 UP 主页的初始收听模式；在 UP 主页明确显示可切换的三模式。切换清空旧结果并重载，详情/分页/空态搜索使用当前模式。不改收藏、倍速、断点、账号或权限规则。
- 复用现有颜色、ChoiceChip、Wrap、空/错态。大字可换行，至少48dp触控，深浅色及320dp/200%文字/键盘检查。没有新艺术资产，因此不调用生图模型。
- 范围外：上一轮审查中其余播放、登录、安全、备份等问题；不把本次改动声称为整体审查问题已修复。不生成正式APK。

验收：空态可选UP并直接查人；四分类关键词保留和请求隔离；UP分页及重试；UP主页类型明确且能切换；现有视频筛选和播放模式回归；原生搜索界面截图检查。
