# B听视觉与交互规范基线

2026-10-24 用户认可 B「闭眼听友」整体 UI 方向，希望补齐方案，让以后新增功能保持一致。

本阶段交付是规范及项目约定，不修改应用代码或生成正式安装包。规范的唯一正文放在 [docs/design/bting-design-system-v1.md](../../design/bting-design-system-v1.md)，便于以后长期维护，避免两份规格并行漂移。

成功标准：

1. 已选品牌延展到颜色、文字、尺寸、组件、页面路径、异常状态及无障碍要求。
2. 已核验的播放/数据规则与待实施的 UX 修正明确分开。
3. 提供新增功能模板，并在 AGENTS、贡献指南和 PR 模板接入规范。
4. 计算色板对比度，核查本地链接和文档差异；不将文档验收冒充应用回归。

具体视觉实施将沿用此规范和已获认可的方向；常规细节按项目约定直接落实。新业务或重要交互变化仍需写清影响，不要求用户重复确认已认可的 B 风格。

## 本阶段核验

- 重新核算 49 组色板组合，均满足文档设定的对比度目标；检查 47 个本地文档链接，无缺失目标。
- 只读对照现有页面、播放代码和测试文件，并由独立审阅核查规范；已将迷你播放条的适用范围明确为现有主页面，避免引入全局常驻改造。
- 文档差异检查通过。本阶段未修改应用代码，未运行 Flutter / Android 回归，未制作或发布 APK。
