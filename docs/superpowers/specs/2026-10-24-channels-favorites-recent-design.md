# B听：四频道分类、收藏页内容切换与常驻迷你播放器统一方案

日期：2026-10-24。范围：Blisten 下一轮功能改造。**用户已确认 v4 及完整方案，并授权修改、测试、打包上传。实施分支 codex/channels-library-v1.2，目标版本 1.2.0+3；完成状态以测试和发布报告为准。**

本文件把此前分散讨论的需求合并为本轮改造的统一入口，覆盖频道与分类、手动收藏、收藏页四视图和常驻迷你播放器。原有规范用于了解已发布行为；本文记录拟改造行为，不将设计写成已发布能力。

## 1. 用户决定与当前边界

| 已确认的决定 | 本轮对应要求 |
| --- | --- |
| 四大频道，每个频道有自己的热门等内容分类 | 发现页改成频道 → 专属分类 → 资源列表 |
| 收藏也分四频道，收藏多的排在上面 | 收藏纵向分组、按收藏作品数量降序 |
| “全局取消播放自动收藏，必须用户自己点击才收藏” | 取消全部播放引发的收藏；自动保存收听记录与进度 |
| 接受最近收听方案二，随后要求把四个模块移到收藏页 | 收藏首页采用收藏／在听／缓存／关注单行标题导航，取代原单独“最近收听”快捷行；保留“我的”次要菜单入口，底栏仍为三个 |
| 将四项切换与页面标题合并为唯一一行 | 不再另设“收藏”大标题；默认收藏选中，选中项放大、加粗、变色，点选切换内容；具体视觉见待确认 v4 图稿 |
| 取消书架右上角续播角标，改为底部常驻迷你播放器 | 移除角标；有当前会话显示当前内容，否则显示本机真实上次收听内容，播放时圆形封面旋转 |
| 常驻范围选择“收藏、发现、我的三个主页面” | 固定在三个主页面的底栏上方；不扩展到搜索、详情、设置等其他页面；重启展示上次内容但不自动播放 |
| “快捷入口的设计要先画出界面图，我确认后再执行” | 先提交图稿；未收到图稿确认前不改应用代码、不构建或发布本轮 APK |

已被最新决定替代的旧建议：**不再保留听书满一分钟自动收藏，也不保留听书缓存播放自动收藏；原单独“最近收听”快捷行改为四项单行标题导航，不叠加第五个入口；v3 的页面标题＋下方分段栏合并，不保留两层标题；书架右上角续播角标取消。** 历史规范中的两项自动收藏描述是旧版事实，不能继续作为本轮需求。

本轮仍仅使用 B 站内容源，保留 B听品牌、既有主题与底部导航。图稿确认后的开发、测试与文档更新需要覆盖本文整体，而非只做标题导航或迷你播放器。此方案不自行指定新版本号，不覆盖已发布的 1.1.0。

## 2. 频道、分类与页面的分工

| 层级 | 用途 | 举例 |
| --- | --- | --- |
| 底部页面 | 区分使用任务 | 收藏／发现／我的 |
| 收藏页内容视图 | 按用户行为切换个人内容，四项不是内容频道 | 收藏／在听／缓存／关注 |
| 内容频道 | 区分四种内容及对应收听规则 | 听书／听歌／听现场／听故事 |
| 频道内分类 | 帮助在发现页找内容 | 听书下的广播剧、相声；听故事下的儿歌、动画 |
| 资源 | 可打开、播放、收藏的一条 B 站视频资源 | 一个 BV；可包含多个分 P |

界面统一使用 **听书、听歌、听现场、听故事**。听故事频道补充“儿童 · 儿歌、动画、故事”，这里的“听故事”沿用儿童模式，并非把成人悬疑小说等内容迁过去。动画只播放音频。

二级分类是发现内容的入口，不新增一套强制填写的收藏标签，也不改变频道的倍速、续播规则。UP 主用于寻找创作者，继续作为独立搜索入口，不成为第五个内容或收藏频道。

## 3. 发现页：四频道和完整分类

### 3.1 首版分类清单

| 一级频道（固定顺序） | 二级分类（显示顺序） | 频道说明 |
| --- | --- | --- |
| 听书 | 热门、有声小说、广播剧、评书、相声、悬疑、玄幻仙侠、名著悦读 | 保留原听书的题材入口，广播剧／相声等不再与听歌并列 |
| 听歌 | 热门、华语、经典老歌、翻唱、纯音乐、欧美、日韩 | 面向歌曲和音乐内容，短曲也可展示 |
| 听现场 | 热门、演唱会、音乐节、Livehouse、舞台现场 | 已录制现场内容，不引入实时直播 |
| 听故事 | 热门、儿歌、动画、睡前故事、童话寓言、启蒙 | 儿童内容；动画仅收听声音 |

“热门”属于当前频道，不能四个频道都请求原来的有声小说结果。热门基于对应频道的 B 站相关检索与播放量排序结果，不标称 B 站官方榜单、实时全站热榜或经过人工审定的精选内容。儿童分类不代表搜索结果已做适龄审核。

### 3.2 页面顺序与切换

1. 页面标题和链接导入入口。
2. 一级频道栏：听书／听歌／听现场／听故事，顺序固定，不受收藏数量影响。
3. 搜索入口：提示词随当前频道变化。
4. 当前频道的二级分类栏，默认选“热门”。
5. 当前分类内容列表，以及与该分类匹配的已有主播推荐等辅助内容。

频道和分类必须视觉上分成两层。窄屏或大字时可以横向滚动／自适应换行，不能为了放下文字而缩小到难以点击的尺寸。

- 每个频道分别记忆上次分类与滚动位置；切到其他频道再返回、从详情返回时恢复。重启可恢复上次频道与分类；不承诺恢复进程退出前的精确像素位置。
- 切换分类不改变正在播放的作品，不改变已收藏资源的频道归属。
- 只加载当前需要的内容，不启动时并发拉取四个频道的全部分类。
- 请求与缓存按“频道＋分类”区分；快速切换时，较早请求返回不能覆盖当前频道，也不能写入另一个分类的缓存。
- 切回已加载分类可复用有效缓存；手动刷新只刷新当前分类。失败保留已有内容并可重试，空结果显示换分类／搜索入口。
- 如果已有离线内容作为失败后的备用入口，优先展示当前频道的缓存，避免把其他频道内容混成当前分类结果；完整缓存仍从现有缓存页进入。
- 原听书主播推荐留在听书对应分类；其他频道没有真实配置时不展示虚构主播推荐。

### 3.3 搜索、更多与导入的频道继承

- 从当前频道打开搜索、分类“更多”或链接导入，默认沿用当前频道；用户可以主动修改。
- 分类“更多”携带该分类的检索词与频道，不能统一跳回有声小说。
- 搜索页并列入口为听书／听歌／听现场／听故事／UP 主；UP 主查询不套用某一频道的题材词。
- 从 UP 主结果进入其主页，沿用最近内容频道，并保留四频道切换；详情、分页与导入保持归属一致。
- 链接、BV 号、分享文本及原有短链接、指定分 P 的解析能力继续保留。
- 单纯解析或打开详情不收藏。如果导入提交动作直接收藏，按钮明确为“添加到收藏”，并显示所选频道；点击这一明确动作视为用户手动收藏。
- 不根据标题自动猜测并改动已有收藏归属。

## 4. 收藏页：单行标题导航与四频道收藏

### 4.1 四视图单行标题导航

- 收藏页顶部唯一一行为 **收藏／在听／缓存／关注**，既是页面标题也是内容切换入口，替代原 AppBar 标题和下方分段栏两行；不再另写一个“收藏”大标题。这四项是个人内容视图，不是听书／听歌／听现场／听故事四个内容频道。
- 常规文字尺寸下整行高约 56 dp，不含系统状态栏；四个等宽点击槽，每项点击区域至少 48×48 dp。选中文字增大时仍在原槽位，不使相邻标签横移，不放大整个点击区域，也不引起下方内容高度跳动。
- 首次进入默认“收藏”选中。选中项建议约 24 sp、加粗、主题强调色和短下划线；其余三项约 16 sp、常规字重和次要文字色，四项在同一基线上。不用整条胶囊底框、大背景统计卡或导航图标。
- 点选时在原位以约 180 ms 过渡字号、字重和颜色，同时切换下方内容；系统减少动效时关闭过渡，直接显示最终状态。读屏提供标签名称和选中状态，不仅依靠颜色表达选择。
- 窄屏或大字时允许整行横向滚动，并确保选中项可见；不强行缩字号。仅在系统字体缩放或安全边界适配确有需要时增高，同一适配条件下切换选中项不改变导航高度。
- 顶部只显示四个名称，不显示计数。数量融入各视图已有内容标题、管理工具栏或频道标题，不为总统计另加整行；四项口径仍遵守下表。
- 点击在收藏页内部切换内容，不 push 到四个重复顶级页面；从详情返回恢复原视图和滚动位置，各视图分别保留会话内滚动状态。嵌入的在听、缓存、关注复用内容与必要操作，不再显示原独立页的大 AppBar 标题或返回栏。
- “在听”是“最近收听”的短标签，包含真正听过的未收藏内容和已播完内容，不表示仅正在播放或未播完。
- 原单独的“最近收听 →”快捷行由“在听”替代，不再叠加第五个入口；空收藏或首次使用时四项标题导航也保留。
- 收藏视图按下节的四频道规则分组；在听按最后收听时间排序；缓存和关注沿用各自已有排序与管理能力，不按收藏数量重排。仅加载当前视图所需的数据，不因为显示导航拉取所有远程列表。
- “我的”移除原四块大统计栏；保留“我的收藏／最近收听／离线缓存／关注的 UP 主”等既有普通菜单作为次要入口，点击切换到底部收藏页对应视图，复用同一数据、状态和内容组件，不维护页面副本。

合并后让首屏少占一行标题是设计目标，不是已经测量的显示收益；具体可用内容高度需要实现后在相同设备、字号与安全区域下验证。

| 标签 | 数量口径 | 内容说明 |
| --- | --- | --- |
| 收藏 | 按 BV 去重的已收藏作品数 | 一个多分 P 视频仍计一项 |
| 在听 | 按 BV 去重的实际收听记录数 | 含未收藏、零秒进度和已播完的有效记录；详见第 5 节 |
| 缓存 | 已完成且可用的音频分 P 条数 | 不含排队、下载中、失败或失效文件；这些任务仍在缓存视图管理 |
| 关注 | 已关注的 UP 主人数 | 不按其投稿数计算 |

四项数量单位不同，不合并成“总资源数”。数量只在对应视图的已有标题、管理工具栏、频道标题或次要菜单中呈现，相关无障碍描述分别明确“项收藏／项收听记录／条已缓存音频／位 UP 主”；顶部标题导航不展示计数，不把未知或加载中的数量伪装成零。

### 4.2 收藏排序与数量

- “收藏”视图按四频道纵向分组，一个 BV 计一项，多分 P 不增加作品数量。
- 频道按收藏数量降序；数量相同时依次为听书、听歌、听现场、听故事。
- 这是收藏页排序；发现页四频道顺序始终固定，两者不联动。
- 每组默认预览最多 6 项，标题显示频道名与总数量，并提供“查看全部”进入该频道完整收藏列表。
- 组内沿用现有最近更新时间倒序，不将其误称为严格的收藏时间排序。
- 添加、移出或移动作品后数量和内容及时更新；浏览中不突然移动整个分组，下次重新进入收藏页再按新数量调整分组顺序。
- 部分频道没有收藏时，放在有收藏频道之后，以紧凑空态和“去发现”入口展示；去发现时选择相应频道。
- 四频道均为空时使用整体空收藏界面，不显示四个重复的大空态；四项标题导航和底部迷你播放器始终保留，仍可进入“在听”。
- “我的 → 我的收藏”切换到收藏页的“收藏”视图，复用同一数据和分组规则，不维护两份收藏。

### 4.3 收藏必须由用户明确选择

四频道都不得因在线播放、累计播放时长、分 P 连播、播放完成、缓存播放、恢复进度或重新启动而自动加入收藏。下载缓存也不能隐含收藏动作。

允许加入收藏的入口是明确的“收藏／添加到收藏”等动作，包括清楚标明会收藏的链接导入提交。收藏、收听记录与离线缓存彼此区分。

已有收藏全部保留，不推测哪些是旧版自动加入的并批量删除。取消收藏后当前播放继续，最近进度保留；播放再久也不能重新自动收藏。

同步移除旧版“听书播放一分钟自动加入”等提示与相关自动收藏行为说明；保留版本文档中的历史事实，不把历史发布记录改成新行为。

### 4.4 移动到其他频道

- 收藏卡片长按提供“移动到其他频道”和“移出收藏”，不得把移动实现为删除后丢进度地重建。
- 一个 BV 仍只有一份收藏；移动更新归属与两边数量，保留播放进度、已听状态和有效缓存。
- 旧数据按保存的频道读取，缺失频道按原兼容规则归入听书；不按标题自动迁移。
- 移动前清楚显示目标频道及再次播放规则。例如移到听歌后，再次从列表选择将从头播放；移到其他频道按断点续播。
- 当前正在播放的作品移动后不重新加载、不改变当前进度或突然切倍速；再次选择播放时应用目标频道规则。
- 收藏、最近收听、详情与缓存展示要识别同一资源的新归属，旧会话保存进度不能把它又改回旧频道。

首版收藏只按四频道分组，不再嵌套“广播剧收藏／相声收藏”等二级列表，不扩展自定义文件夹、置顶或手动拖拽排序。

## 5. 在听：最近收听与进度

### 5.1 导航方案

- 收藏首页的“在听”视图承担最近收听入口；内容标题或说明明确为“最近收听”，避免误解为正在播放的列表。“我的 → 最近收听”保留并直达同一视图。
- 底栏仍为收藏／发现／我的，不增加第四个“最近收听”标签；顶部单行标题导航也不增加第五项。
- 切换到“在听”仅展示记录，不自动播放。记录提供实际对应的播放／续播操作。
- 迷你播放器控制当前会话或显示上次收听预览；在听视图用于找回历史内容。收藏为空也可能有历史和当前播放会话。
- 最近收听默认按最后收听时间倒序，可筛选全部／听书／听歌／听现场／听故事。筛选不影响记录保留上限或归属。

### 5.2 记录与进度口径

- 最近收听包含本机实际播放过的作品，既包括收藏，也包括未收藏，按 BV 去重。
- 仅浏览详情、解析链接、加入收藏或播放请求失败，不算已经收听；获得实际播放推进后自动记录。
- “听过”与“当前进度大于零”是不同概念。歌曲从头重播、用户回到零秒或已播完，都不能仅因此丢失已有收听记录。
- 迷你播放器的上次内容、在听视图的记录数量、“我的”里的数量／预览和最近列表采用同一口径；不能出现入口显示零项，点入后却有未收藏记录。
- 实际最近收听时间只由收听更新，不能因为改标题、移动频道或添加收藏，就假装该作品刚刚播放过。
- 记录未收藏作品的目录、分 P、进度和已听状态，保证取消自动收藏后，续播与已听标记仍可用。
- 旧数据用已有可核实的进度、章节与已听信息兼容；没有证据的收藏不虚构收听历史。
- 沿用现有上限：**未收藏收听记录全局最多保留最近 100 项**，不是每频道各 100 项；收藏不因这一上限被移除。页面清楚说明最近记录的范围，不承诺永久完整历史。

### 5.3 删除与播放规则

| 动作 | 结果 |
| --- | --- |
| 移出收藏 | 播放继续，保留最近进度与缓存 |
| 清除收听记录 | 单独确认；删除该资源进度和已听标记，停止匹配的播放／加载；收藏与缓存保留；若被清除的是当前会话或预览目标，迷你播放器改为下一条有效本地历史预览或无记录态，不自动播放；不影响其他作品的当前会话 |
| 删除缓存 | 不删除收藏与收听记录 |
| 切换频道／分类／最近筛选 | 不停止或重新加载当前播放 |
| 从最近列表重新选择听歌 | 遵循原歌曲规则，从头播放；当前会话暂停后继续仍接着播放 |
| 从最近列表重新选择听书／听现场／听故事 | 遵循原断点与分 P 续播规则 |

各频道默认 1.0×、分别记忆倍速等既有规则保留。听故事继续使用原儿童模式的断点续播及分 P 单位“集”。

## 6. 三个主页面常驻迷你播放器

### 6.1 位置、封面与动作

- 取消书架右上角续播封面角标，不在顶栏和底部重复呈现两个续播控制。
- 迷你播放器固定在 **收藏／发现／我的** 三个主页面的底部导航栏上方，三个页面共享同一个状态。搜索、详情、设置等其他页面沿用既有入口，本轮不扩展常驻范围。
- 内容布局为圆形真实资源封面、标题／分 P 与位置、右侧独立播放按钮；主列表预留实际播放器高度与系统安全区域，不能遮住最后一项。
- 有当前有效会话时优先显示该会话，包含暂停、缓冲、失败和播放结束状态；没有会话时读取本机真实上次收听记录，显示其封面、标题和可核实位置。不因有收藏就假定已听过。
- 上次内容按真实收听时间或有效的 last-session 引用选择，不能按收藏 `updatedAt` 假造最近播放。收藏、改标题和移动频道不改变这一目标。
- 封面／标题只打开播放器；已有会话不重载，无会话时打开待播放预览，不自动启动。右侧播放按钮单独控制播放／暂停／重试，不能通过点封面隐式恢复声音。
- 移出收藏不清空播放器，也不打断播放；清除当前收听记录时按第 5.3 节停止并更新目标，不能留下已清除内容的虚假可续播状态。

### 6.2 冷启动与播放规则

- 冷启动仅恢复本地元数据与待播放状态，不请求音源、不自动播放，也不先 play 再 pause 来伪造静默恢复。
- 点击待播放预览右侧的播放按钮才发起正常播放：听歌遵循重新选择规则，从首个分 P、零秒开始；听书／听现场／听故事按原分 P 和断点恢复。位置文案可展示真实上次位置，但听歌预览需说明“重新播放”，不能承诺接着该时间开始。
- 同一已加载会话内暂停后再播放，四频道均保持当前分 P 和位置；只打开播放器页面不视为重新选择资源。
- 异步恢复本地记录期间，用户已选择新内容、清除了记录或发起播放时，旧恢复结果不能覆盖用户的新选择。有效当前会话优先于迟到的历史恢复。
- 读取失败、记录失效和没有记录不能混为成功恢复；失败允许重试，失效目标不伪造封面、位置或可播放状态。

### 6.3 空态与动效

- 首次使用或全部记录被清除后仍保留迷你条位置，显示“还没有收听内容”和“去发现”；不伪造作品封面，不显示一个假装可播放的按钮，播放控制禁用或不展示。“去发现”是明确导航动作。
- 有记录但封面加载失败时采用既有统一占位，保留真实标题；不要用其他作品图片冒充上次封面。
- 圆形封面仅在底层确认 **真正播放中** 时旋转，约 10 秒一圈；暂停、缓冲、错误、结束或系统减少动效时停止，保留当前角度。
- 暂停时不在封面上叠加三角播放遮罩；右侧已有独立播放按钮，保持封面可见。旋转不作为唯一播放状态，按钮、文案和无障碍描述同步真实状态。
