# B听 1.1 实施与发布计划

使用现有 Flutter、播放器、存储和正式四包构建流程。根代理串行执行 Flutter/Gradle/ADB/Git；子代理按文件所有权完成儿童和更新两个独立模块。设计见 [本次设计](../specs/2026-10-24-children-update-design.md)。

1. **建立检查点与测试。** 核对干净基线、正式签名和 1.0 发布；保留模拟器旧正式包以便升级验收。儿童测试先复现未知模式回落/缺少入口，更新测试先复现无自动提醒、版本处理及重复请求缺口。
2. **儿童模式。** 扩展 ContentMode、独立速率键、发现热词和模式文案；复用导入、UP、缓存和进度链路，补儿童语音焦点策略。验收旧数据读取、儿童往返、短儿歌搜索、四模式速率/续播、五搜索标签双主题 320dp/200% 字体、跨进程恢复。
3. **更新提示。** 自动宿主放主题重建范围之外，共用手动提示；增加超时、去重、频率与正式版本/HTTPS 更新链接判断。验收启动非阻塞、较新/同版/较旧/无效响应、离线静默、手动重试、后台和重复点击、下载入口。Android 用本地响应验证未来版本自动提醒。
4. **版本与回归。** 同步 AppMeta/pubspec 为 1.1.0+2；更新设计、使用说明和隐私文案。运行 unit、lint、integration、online；诊断并修复本次变化导致的问题。独立 review 后提交干净源码。
5. **签名 APK 与真实升级。** 使用原证书执行四包脚本；核验静态内容和对应原生源码。生产候选包测试儿童搜索/导入/播放。保留或恢复专用模拟器的 1.0 测试状态供线上更新验证，不能操作个人手机或真实用户数据。
6. **发布与回读。** 推送源码、确认远程 CI，标签指向 APK 对应源码。发布 v1.1.0 与四 APK、校验和及源码材料。用旧 1.0 实际点击检查更新识别 1.1，再覆盖升级，核对收藏/进度/主题与最新版本提示。回读 Release、公开附件与哈希；建立仓库外 bundle 并验证恢复，保存验收记录。

每项记录实际命令、结果、失败后的复验和未测试边界，不以调试夹具结果替代正式 APK 或公开发布结果。旧 1.0 自动弹窗无法追补，1.1 自动提示仅在存在更高正式版本时出现。
