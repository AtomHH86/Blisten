## 本次待确认的入口

1. “收藏”标题下方为独立紧凑入口：时钟图标、**最近收听**、右箭头。整行可点，仅导航到最近收听列表，不直接开始播放。
2. 标题与入口位于收藏内容滚动区上方；默认行高约 56 dp、左右间距 16 dp，大字模式按内容增高，不固定高度截字。
3. 有收藏、无收藏时位置一致；空收藏仍允许查看历史。真正没有收听记录时，点入列表显示相应空态。
4. 沿用奶油白／深蓝背景与珊瑚粉强调色、已有 B 形闭眼耳机角色；不更换品牌，不新增底部标签。
5. 底栏保留收藏／发现／我的，“我的”里的最近收听入口保留。迷你播放器按实际会话显示，与收藏是否为空无关。

## 已确认业务要求及后续实施范围

- 四频道为听书、听歌、听现场、听故事（儿童）。发现页按频道展示各自二级分类，避免频道与听书分类混排。
- 收藏以四频道纵向分组，按唯一 BV 的收藏数量降序；同数按上述频道顺序。组内保留最近更新优先。浏览期间不跳组，再次进入时更新分组顺序。
- 设计示例为听歌 12、听书 8、听现场 4、听故事 2；画面仅显示首屏，听现场和听故事位于下方滚动区域。实际排序由本机收藏决定。
- 各组预览最多 6 项，提供“查看全部”；不压缩字号来强行把四组都塞进首屏。部分频道为空时用简短入口置于后方；全部为空时采用图中的整体空态。
- 全局取消播放引发的自动收藏，包括满一分钟和缓存播放等入口；仅明确点击收藏动作才加入。已有收藏保留。
- 链接导入如果直接保存收藏，提交按钮应明确写“添加到收藏”，避免“添加资源”隐藏收藏行为。
- 自动保存收听记录和进度；最近收听包含未收藏作品。统一入口数量、预览、续播目标与列表的数据口径，不能仅依据当前进度大于零判断是否听过。
- 最近收听继续保留现有未收藏最多 100 项的边界；空态最终文案收紧为“可在最近收听中查看近期记录”，不暗示永久保留所有历史。图中文字只作布局参考。
- 移出收藏后继续播放并保留最近进度；清除收听记录沿用单独确认及停止匹配播放的现有规则。
- 本轮应用改造包含“移动到其他频道”：保留收藏唯一性、进度和缓存，并说明模式对再次播放规则的影响；须等图稿确认后实施。
