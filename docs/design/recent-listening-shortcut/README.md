# 收藏页一行标题导航与常驻迷你播放器：待确认界面稿 v4

日期：2026-10-24。状态：**最新图稿待用户确认，应用未实施、未发布**。

用户先要求“快捷入口的设计要先画出界面图，我确认后再执行”，随后明确：将“我的”页收藏／在听／已缓存／关注四块移到收藏页并缩小占位；取消书架右上角续播角标，由底部常驻播放器显示上次收听封面，播放时旋转圆形封面。本轮已确认常驻范围为**收藏、发现、我的三个主页面**。

用户最新提出将“收藏”标题与下方四项合为一行，默认显示收藏，点击其他项时放大字体并变色。v4 将这一建议画成待确认稿：只保留一行标题导航，以当前选中项同时承担页面标题，不再重复占两行。

本目录只保存界面稿；完整功能范围以[四频道、专属分类、手动收藏与最近收听统一方案](../../superpowers/specs/2026-10-24-channels-favorites-recent-design.md)为准。原有四频道分类、收藏按数量排序、取消自动收藏及最近收听的数据规则均保留，不因本次入口变化遗漏。

## 1. 四个名称直接组成标题导航

系统状态栏下仅放 **收藏｜在听｜缓存｜关注** 这一行，次序固定，默认选中收藏；取消上方独立“收藏”标题以及下方带底框的分段栏。默认约 56 dp 高（不含系统状态栏），比两行稿少一行是布局目标，实际空间收益待实现后测量。

- 四个固定等宽点击槽，同一文字基线，选中项不移到最左，也不把其他名称挤动。
- 选中项约 24 sp、加粗、主题强调色，附短下划线；其余三项约 16 sp、常规字重和次要文字色。字体变小不缩小点击区域，每项仍至少 48×48 dp。
- 点击后切换下方内容，用约 180 ms 的字号／字重／颜色过渡；整行高度和下方内容起点不随选中项变化，减少动效时直接切换。
- 导航只放名称，不放数量、图标、大底框或胶囊背景。数量融入各视图已有内容标题、频道标题或管理工具栏，不为总数量再加一整行。
- 窄屏和系统大字优先允许同一行横向滚动并使选中项可见，必要时自适应增高，不缩小系统字体、不截字；这些是待验收规则。
- 嵌入的在听／缓存／关注内容不再重复显示原独立页面的大标题或返回栏。

| 切换项 | 展示内容与数量 |
| --- | --- |
| 收藏 | 原有四频道纵向分组，按唯一 BV 收藏作品数计数；频道按收藏数量降序 |
| 在听 | 最近收听，包含听过但未收藏或已经播完的内容；按有收听记录的唯一 BV 计数，不只统计当前播放 |
| 缓存 | 现有缓存管理内容；列表内统计只计已完成且可用的音频分 P，不把排队、下载中或失败任务算作已缓存 |
| 关注 | 关注的 UP 主列表；数字为 UP 主人数 |

点击后直接切换下方内容，各视图保留浏览位置。字号、字重、文字颜色与短下划线共同表达选中状态；不再额外叠加一个“最近收听”入口，也不增加底部主标签。只有收藏视图使用“四频道按收藏数量排序”，其他视图保持自身排序。

“我的”移除原大统计栏，既有普通菜单作为次要入口，打开同一个对应视图，不另建重复页面；账号、外观、定时和设置仍在“我的”。

## 2. 常驻迷你播放器

书架标题右侧的圆形续播角标取消。底部主导航上方保留一条紧凑播放器，在收藏／发现／我的三个主页面始终占位；搜索、详情等独立页面不因本次改造新增常驻条。

| 状态 | 显示及动作 |
| --- | --- |
| 有当前会话 | 优先显示当前作品及真实状态，不被历史读档覆盖 |
| 重启后无会话、有历史 | 读取本地上次收听封面、标题和位置，标识为上次收听；不加载音源、不自动出声，按播放才开始 |
| 从未收听／记录已清空 | 圆形占位图＋“还没有收听内容”＋“去发现”；不显示虚假作品，不提供无效播放按钮 |
| 正在播放 | 圆形资源封面约 10 秒一圈缓慢旋转，右侧显示暂停按钮 |
| 暂停、缓冲、失败 | 封面停转；分别显示播放、加载或重试状态，不用旋转伪装播放中 |
| 减少动效开启 | 播放仍正常，封面不旋转 |

封面保留资源本身的图片，缺图才使用统一占位；不再在封面上重复叠加播放三角，右侧保留唯一的主播放控制。点封面或标题进入播放器；待播放预览不因打开页面就开始播放。

上次内容以真实收听时间或最后成功会话为依据，不按收藏元数据更新时间误选。清除该记录后不会恢复已清除内容；移出收藏不清除当前播放或最近进度。

播放规则继续区分：冷启动待播放态点歌曲使用原规则从头播放，其他三频道按已保存位置继续；正在运行的会话暂停后继续均保持当前位置。歌曲预览文案用“重新播放”，不以“继续上次位置”误导。

## 3. 图稿涵盖与未涵盖

- 当前图示：收藏视图、在听视图、首次空态；常驻条的上次收听、播放中、无记录三个状态。
- 未在图中展开：缓存与关注的具体列表、发现页完整分类、播放器详情与错误态。这些属于统一方案的已有功能／验收范围，不能把未画状态当作已经验证。
- 收藏首屏按空间展示部分频道，未显示完的听现场、听故事（儿童）等内容继续向下滚动查看；实际数量决定顺序。图中多露出的内容不是新增频道或减少预览项造成的。
- 本阶段只核对画面和业务一致性。小屏、大字、无障碍、真实旋转、冷启动恢复等运行验收须在用户确认图稿并完成应用实现后执行。
